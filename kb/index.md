# Knowledge base

This folder is the project knowledge base. A pull request that changes code updates a page here, along with `CHANGELOG.md` and `README.md`, unless the pull request carries a docs opt-out marker.

## Pages

- [Checks](checks.md) — the deterministic rules, how to run them, and how to configure them.

Add a page when a change needs an explanation that does not belong in the README: a rule's intent, a workflow, or a decision later readers will need.
